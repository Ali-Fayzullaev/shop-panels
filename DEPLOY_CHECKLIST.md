# Чек-лист деплоя

## 1. Подготовка окружения на сервере:
- [ ] Node.js версии 18+ установлен
- [ ] npm или yarn установлен
- [ ] PM2 установлен (опционально): `npm install -g pm2`

## 2. Загрузка файлов:
- [ ] Скопировать весь проект на сервер
- [ ] Убедиться что .env.production скопирован как .env.local на сервере
- [ ] Проверить права доступа к файлам

## 3. Установка зависимостей:
```bash
npm ci --only=production
```

## 4. Сборка проекта:
```bash
NODE_ENV=production npm run build -- --webpack
```

## 5. Запуск в продакшн:
```bash
# Простой запуск:
NODE_ENV=production npm start

# Или с PM2:
pm2 start ecosystem.config.json
```

## 6. Проверка:
- [ ] Сайт доступен по URL
- [ ] Нет ошибок WebSocket HMR
- [ ] Сайт не перезагружается автоматически
- [ ] Все страницы работают

## 7. Мониторинг:
```bash
# Проверить процессы:
pm2 list

# Посмотреть логи:
pm2 logs shop-panels

# Проверить статус:
curl -I https://marmarill.kz
```
