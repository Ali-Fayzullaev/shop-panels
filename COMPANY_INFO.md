# Данные компании

Все контактные данные компании находятся в файле `src/lib/company-info.ts`.

## Как изменить данные компании

1. Откройте файл `src/lib/company-info.ts`
2. Измените нужные данные в объекте `COMPANY_INFO`
3. Сохраните файл - изменения применятся автоматически

## Какие данные можно изменить:

- `name` - название компании
- `phone` - основной телефон для показа
- `phoneClean` - телефон для ссылок (только цифры и +)
- `email` - электронная почта
- `instagram` - ссылка на Instagram
- `whatsapp` - номер WhatsApp
- `telegram` - ссылка на Telegram
- `address` - адрес офиса
- `logo` - путь к логотипу (файл должен быть в папке `public/`)
- `workingHours` - режим работы
- `description` - описание компании
